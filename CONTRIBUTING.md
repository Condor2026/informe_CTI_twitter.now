# Guía para contribuciones

Este repositorio es público y abierto a mejoras. Si deseas contribuir, sigue estas pautas:

1. **Informes**: Si encuentras errores o nuevas evidencias, abre un issue o envía un pull request con los cambios.
2. **Estilo**: Mantén el tono objetivo, técnico y basado en fuentes verificables.
3. **Fuentes**: Incluye siempre referencias a fuentes abiertas (enlaces, capturas, etc.).
4. **Aviso legal**: Al contribuir, aceptas que tu contenido se distribuirá bajo la misma licencia CC0 y renuncia de responsabilidad.
5. **Proceso**: ORDENADO Y PROFESIONAL.
   - Fork el repositorio.
   - Crea una rama con tus cambios.
   - Envía un pull request describiendo las modificaciones.

Gracias por ayudar a mantener esta investigación transparente y actualizada.
